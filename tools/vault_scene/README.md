# 分阶段机关预览

独立预览入口：`vault-preview.html`。当前主页仍使用已确认的6.4秒SVG开场。

新预览为12.8秒：七段立体机关共9.2秒，再接原来的3.6秒轨迹、姓名与散落。用实体几何、曲面倒角、独立铰链、卡榫、局部光和透视镜头表现运动。没有把静态图整体旋转当作机关变化。

| 秒数 | 阶段 | 可观察的变化 |
|---|---|---|
| 0–1.2 | 枝脉苏醒 | 六组细枝出现，远近晶叶靠近 |
| 1.2–2.5 | 晶叶归位 | 30片晶叶转向、归位 |
| 2.5–4.0 | 外框拼合 | 十二组支架分批收拢、翻转定位 |
| 4.0–5.3 | 内层错位 | 中层翻面、轴向换位；中心部件归位 |
| 5.3–6.7 | 逐级脱扣 | 六个卡榫分别退出，局部亮光依次传递 |
| 6.7–8.15 | 中心开瓣 | 六瓣围绕各自外侧铰链翻开 |
| 8.15–9.2 | 穿门入境 | 镜头穿过通道，晶叶向两侧离开 |
| 9.2–12.8 | 姓名显现 | 原轨迹与姓名动画，路径和字体保持 |

造型与动作参考官方菩提参悟、佛怒轮回及多层阵构的视觉规律；全部网页几何重新绘制。不是官方模型、原片或影视级物理仿真。第三方仅使用Three.js 0.187.0，MIT许可证随预览发布；依赖打包在本地脚本中，运行时不请求CDN。

可暂停、重播、拖动进度或点击阶段。系统减少动态时停在静态展示；切走标签页暂停。手机预览仍可主动查看，主页原有手机策略没有改变。预览没有统计、数据库或音乐请求。

源文件：`scene.js`为建模与确定性时间轴，`preview.js`为预览控制。构建及依赖来源记录在本机项目工件目录`vault-mechanism-3d-20261114`，没有修改项目依赖环境。发布白名单仅为预览HTML、打包JS和Three许可证。

本轮构件细化：金属拉丝微表面、黑钛嵌槽、分层晶体、带保持帽的轴承、精细骨脊与楔形锁舌。阶段、时长和暂停后resize重绘逻辑保持。
