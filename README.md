# Jia Li · 李嘉

个人学术主页：**[li2ga.github.io](https://li2ga.github.io/)**。

这里是网站的公开发布仓库，包含静态页面、公开简历、媒体素材和公开统计快照。可编辑的资料与页面生成工具保存在独立的本地源码目录；发布时只复制明确允许公开的文件。

## 本地预览

克隆此仓库后，在仓库目录启动静态服务器：

```powershell
python -m http.server 8788 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8788/>。本机配置的独立 Python 环境也可使用 `research-python` 替代 `python`。按 `Ctrl+C` 停止服务。

预览静态页面不需要安装 Node.js 依赖。访问统计和留言入口依赖线上服务，离线时可阅读主页及简历。

## 在可编辑源码中修改

以下生成工具存在于独立的本地源码中，公开发布仓库只保留成品和统计更新工具。

- **正文、论文、经历与奖项**：编辑 `content.json` 的相应中英文内容，再运行 `python tools/build_site.py`。姓名在两种语言下均保留 `Jia Li | 李嘉`。
- **点击 emoji**：编辑 `script.js` 中的 emoji 数组，再运行 `python tools/build_site.py` 更新主页内的交互代码。当前暂停十二生肖，以及月相组中带暗面或表情的月亮；旧项目保留在注释中。
- **配色、布局与动态**：修改 `site.css`、`script.js` 或 `art-loops.js`。背景选择、渐隐渐现、固定 / 滚动布局和系统“减少动态效果”的回退均应保留。
- **标题字体**：参考截图的英文姓名使用 Georgia 常规字重；右上角 Aa 可切换“参考图 / 前版 / 原版”。前版 TeX Gyre Termes Bold 和最初 NameLatin 保留。Georgia 使用设备自带字体，不复制或公开系统字体文件；缺少 Georgia 的设备使用 serif 回退，字形可能略有差别。中文姓名和竖线保持原样。
- **标签页图标**：当前使用已有的金色火莲 `assets/backgrounds/fire-lotus-gold-v1.png`。运行 `python tools/prepare_favicon.py` 后重新生成页面；小图标导出需要 FFmpeg。背景原图不改变，PNG 与 ICO 保留透明度。原环莲、粉金火莲及蓝色 JL 方块仍保留，便于切回。
- **PDF 简历**：确需更新 PDF 时再运行 `python tools/render_cv.py`，并检查实际分页；单改网站图标无需重新渲染 PDF。

原照片保持完整比例。火莲背景保留原始分辨率的无损 PNG；浏览器标签页另导出标准小尺寸图标。首次进入有开场动画，再访行为和显示偏好保存在当前浏览器中。

### 加载与画质

样式、主交互与音乐控制在构建时从 `site.css`、`script.js`、`background-music.js` 嵌入HTML，随正文一并送达，避免独立样式或脚本请求延迟导致首屏等待；修改这些源文件后需要重新构建页面。六个背景模块合并为 `background-runtime.js`，在需要桌面动态背景时才加载。手机、系统减少动态或静态档不请求该文件。背景脚本延迟或失败时，正文、语言按钮和音乐仍可使用；已下载的完整原图继续显示。修改独立背景模块后，运行 `python tools/build_site.py` 重新生成背景文件，并一起发布。

主页照片使用原生4031×3024的渐进式JPEG，保留原图解码像素、EXIF和ICC，约5.24MB；下载过程中可逐步显示。点击照片仍打开原来的JPEG。十二张火莲在主页传输原生尺寸的无损WebP，合计从约15.02MB降至10.67MB；PNG原文件保留，逐像素校验一致。附加光焰按当前可见形态加载，当前光焰未准备好时不抢先预取下一形态；歌单音频均在点击播放后才下载。

火莲演变新增“金枝柔焰 / Golden branches”：细金枝从中心有序向外展开，粉白火焰沿枝架柔和散开。新图保留原生透明 PNG，内部动画对金属骨架作保护；“凝聚形态”和“重铸流焰”等旧版仍可切换对照。可直接访问 `?background=lotus&lotus=branches&artmotion=loop`。

[动态对比页](https://li2ga.github.io/motion-preview.html)左侧显示所选原图，右侧显示恢复后的原图细纹与火舌流动。当前火莲外观基线为发布历史 `fe08ca2`，又比 `50bdd7c` 早一版：原图轮廓与细纹保留，材质位移与短小火舌参与动态，火莲不使用后来的烟雾状燃料场；不能用于验证整张原图的火舌全部熄灭。青白寒莲额外保留40片有分枝的六角雪花，向下飘落并横向错开；雪花不依赖视频模块，对比页可单独关闭。全部十三形态与主页共用同一渲染器。早期 GIF 样片（512×512、96帧、8秒、约8MB）仍可选查看/下载，不默认下载；对比页不采集访问记录。

## 异火图鉴与实时流焰

[二十三种异火图鉴](https://li2ga.github.io/heavenly-flames.html)使用四张原生 1536×1024 透明 PNG，按图集坐标逐一展示二十三种异火。原图完整保留，不切割或有损转码；只加载当前选择所需的图版。深浅底色、静态/动态与逐焰选择均可切换。

名称、已知配色与形态作为创作依据，图片是原创视觉演绎，不能作为动画官方定稿。没有逐种核对动画登场镜头；火云水炎、万兽灵火的外观特别标注为推演。官方参考视频与截帧不随网站发布。

二十三种异火图鉴沿用 `art-loops.js` 的实时绘制：静态层保留莲体及受保护的金属结构，分离出的原始焰层在双缓冲纹理中向上输送，根部持续补焰，时变卷流改变路径，冷却消耗使火舌消失。动态层按显示像素设置分辨率，单边上限768像素；原图文件与原始纹理保留，动态帧是重新绘制的像素。验证须检查实际画面中的原火舌在熄灭后消失，仅检验额外燃料场归零不足以证明此效果。该方案仍是二维图像焰层输送，并非完整三维燃烧。原图、静态/减少动态回退、显淡及布局控制保留。图鉴和对照页支持手机动态；主站窄屏继续使用原来的静态回退。图鉴不采集访问记录。

主页明确选择的火莲（包括带 `lotus=` 的链接）使用高下载优先级，自动装饰仍保持低优先级。加载等待上限从20秒放宽到90秒，避免慢连接中的有效图片被过早放弃。原5.6MB头像和所有火莲原图未改动；23秒延迟的受控请求已验证旧版失败、新版仍能显示真实动态图。

主页左侧沿用 `fe08ca2` 的原图细纹与短火舌流动，右侧在同一完整原图上合成已审阅的粒子光焰；十三种火莲均保留原图轮廓、莲体及受保护金属结构。`motion-preview.html` 保留原图实时动效对照，二十三种异火图鉴继续使用其原有焰层输送效果。显淡、静态回退、漂浮、鼠标跟随与独立演变节律均保留；整朵火莲不旋转，火舌内部继续变化。

13款 LTX-2.3 / Wan2.2 视频保留在 `assets/backgrounds/motion/` 和离线制作存档中，主站不再加载或播放它们。模型重绘会改写细纹，即使原生分辨率和无损导出也不能保证原图级细节；上一视频版的亮度去黑底还造成白底暗纹发淡，相关修复候选另行存档。不会把视频存在仓库等同于主站仍在播放视频。

## 新访客的默认流程

无本地历史、无特殊网址参数且系统允许动画时，首次访问播放约3.6秒的轨迹汇聚、姓名出现和线条散落开场，不设点击跳过。普通主域名默认英文、参考图的 Georgia 常规姓名字体，姓名始终为 Jia Li | 李嘉；头像使用星月装饰。桌面默认开启「自动轮换」、选择「清晰」并关闭额外「渐隐渐现」，固定视窗；从火莲开始，每30秒依次切换轨迹、斗数意象、八字意象，再回火莲。额外“渐隐渐现”默认关闭，人物自己的缓慢显现与淡去仍保留，玄重尺和萧炎的最低透明度保持原来的12%，不改成0；线条角色仍按原动画进出。“渐隐渐现”只作用于后来加入的玄重尺、萧炎及线条模式中的角色陪景，不影响火莲主体、斗数/八字意象、正文和照片；陪景会缓慢显现，再逐渐隐去至完全消失，清晰档关闭这层渐隐渐现。静态图案仍可渐隐渐现；系统减少动态时关闭轮换与渐隐，保留静态回退。不会加载整组火莲视频。神灯在「八字意象 / Living elements」，使用独立灯焰规则，金属灯身保持原样。

开场完成后会记住本浏览器已看过，普通再访不重复；语言、背景、布局、渐隐、静动态和字体等手动选择会在本浏览器保存；已有手动偏好优先于新默认值。网址查询参数可以覆盖这些默认值，例如带 `lotus=cold` 的对照链接会定格寒莲并暂停形态演变；这不代表其他新访客的默认画面。宽度1040px及以下隐藏两侧大型背景及其菜单；系统减少动态或直接进入页面锚点时跳过开场。统计请求不需要登录，登录/留言入口在页尾；实际记录能否写入仍取决于原统计服务的可达性。

流星为独立固定视窗层，覆盖所有背景模式与整页滚动；通常在样式启动约3秒后首次出现，随后由四条错开的轨迹间歇划过。蓝金尾迹与星头使用CSS绘制，不增加图片或视频下载；手机保留两条，隐藏标签页时暂停，系统减少动态时关闭。

全局秋风落叶也独立于背景模式：枫叶、银杏和桦叶以不同节律下落、横飘与翻转，桌面12片、手机6片。使用内嵌SVG轮廓和CSS动画，不新增图片、视频或逐帧JavaScript任务；落叶层不拦截点击，随页面滚动仍覆盖视窗。隐藏标签页暂停，系统减少动态或打印时关闭。入场总时长由 `tools/entrance_art.py` 的 `INTRO_DURATION_MS` 统一定义，轨迹、姓名、散落与兜底计时同步调整；修改后需重建页面。

八字与斗数意象各有独立的上升术语层，保留原有形象。两侧各有远、中、近三层书法字体，每个词分别在32–108秒范围内随机取上升时长，出屏后随机等待0.8–9秒再出现，进入和离开视窗时淡去；正文区域留空，固定及滚动布局都能看到。词库在 `tools/cultural_terms.json`，按主题分组，当前八字582项、斗数463项；`tools/cultural_terms.py` 交错编排各组，每个背景用42个轻量文字节点轮换；逐词随机字号、字距、横向位置、轻微倾角与浓淡，初始相位按不等间隔错开，每次出屏重新抽取参数；词序使用洗牌词池，避免同屏同层重复和相邻重复，不为每个词创建逐帧JS任务。近层优先展示具体技法和组合（八字272项、斗数251项），例如质能变、同宫异向、三爻变、挟忌转忌、两头见忌、鸳鸯比翼、制用结构；基础干支和星名放到远层，三层词池互不重复，侧边宽度限制最大字号，长词自动缩字号，古籍成句按逗号分为上下行，每行最多7字。隐藏页面、离开对应背景时暂停，手机、减少动态及打印时隐藏，不新增字体或媒体下载。此层仅展示传统与不同流派的术语，不是个人命盘，也不将各派的解释规则合并；来源记在词库中。

## 统计与可用性

主页优先读取线上公开汇总，正常情况下每 15 秒刷新。原服务不可达时，自动显示本站保存的公开统计与国家地图，并注明最近同步时间。

公开快照工作流设置为每小时第 17 分钟（UTC）运行，也可手动触发；实际执行时间可能有延迟。它只更新汇总和国家地图，不发布 IP、访客明细或登记信息。工作流显式请求 GitHub Pages 构建，避免快照只更新仓库、网页却未更新。

**已知限制**：原留言 / 统计服务在部分网络下仍可能被托管层返回 403。主页的备用统计和邮件联系入口已提供替代路径，但不代表原服务的拦截已解除；无法连到记录接口的访问也不能保证入库。邮件联系不会自动保存为原站留言。Owner 是仅站主可用的管理入口，普通访客无法查看记录。

Owner / Leave 已由原账号更新，当前可观察到原站版本7；Owner 使用 J 图标，Leave 使用鱼身12秒逆时针、外环8秒顺时针的阴阳图标。当前维护连接仍没有原站编辑身份，原账号的更新不等于此连接已经恢复。主页鼠标点击图案同时包含静态阴阳图及同款旋转阴阳鱼，并随 HTML 内嵌，点击时无需等待图标下载；主页标签页继续使用金色火莲。后续应先读取原站最新源码，保留原数据库和管理员配置，避免用旧的本地待发布包覆盖已上线修改。
